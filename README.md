## Important
There is deliberately NO pricing displayed anywhere.

The enquiry form is frontend-only. It opens WhatsApp and email with the enquiry details. Browsers cannot reliably attach a selected file to a WhatsApp/mailto message without a backend or a third-party upload service, so the reference photo must currently be attached manually by the customer in WhatsApp.

## Deploy
This is plain HTML/CSS/JS, so it can be hosted on Netlify, GitHub Pages, Cloudflare Pages, etc.


## Design update
The homepage and shared styling were upgraded to a yellow + white + steel-blue premium/local-business look inspired by the approved reference:
- Sticky white header with logo + Malliga Steel Works name in the top-left.
- Rounded yellow CTA and bilingual toggle.
- Large image-led hero with text on the left.
- Trust/stat strip.
- Rounded product cards.
- Stronger typography, spacing, shadows and section hierarchy.
- Responsive mobile navigation.
